# Template notes

Before publishing or sharing your own stack:

- Remove real `.env` files.
- Remove app config directories.
- Remove tracker/indexer screenshots or names.
- Remove passkeys, cookies, API keys, VPN credentials, and webhook URLs.
- Replace host paths with `CONFIG_ROOT` and `DATA_ROOT` examples.
- Replace private URLs/IPs with service names or localhost examples.
- Do not publish generated databases, backups, logs, media files, or download history.
